Accès aux applications du datacenter

Les applications internes (Airflow, Superset, Outline, OpenProject…) sont hébergées dans notre datacenter et accessibles via VPN.

Remplissez ce formulaire pour demander un accès. Un administrateur traitera votre demande et vous contactera pour finaliser la configuration.

Note : seul l'environnement de développement est disponible pour le moment.

Collez le contenu de votre fichier ~/.ssh/id_ed25519.pub.
Si vous n'en avez pas, générez-en une avec : ssh-keygen -t ed25519

Sélectionner si vous avez besoin d'accéder à une application spécifique via Rancher.
